# 肖八选择题刷题 · 2027 考研政治冲刺 8 套卷

> 单文件网页应用：肖八 8 套卷 264 道选择题的刷题、自动判分、错题本与数据备份，内置账号登录系统，各账号数据完全独立。

**在线使用**：<https://JOJO666888888.github.io/xiaoba-8-practice/>

## 功能

- **账号系统**：注册（用户名 + 密码 + 确认密码）、登录、退出登录；每个账号的刷题记录、错题本、已录答案完全独立、互不影响
- **选项乱序**：每次练习都会随机打乱每题的选项顺序（字母编号始终与原题一致，连续两次练习顺序必定不同），避免只记住选项位置、没记住知识点
- 整套练习 / 错题重练：单选 1—16（每题 1 分）、多选 17—33（每题 2 分，少选得 1 分），交卷自动判分
- 刷题记录：用时、得分、错题详情，支持重新判分、删除、按套卷筛选、导出 CSV
- **交卷后完整复盘**：错题详情、全部作答回顾、错题本都会显示每个选项的完整内容，正确答案绿色高亮、误选项红色高亮
- **错题解析（第一、二套已录入）**：错题后面显示「解析：」，书后简析按选项分段，正确选项绿色、选错的选项红色、其余灰色，一眼看清错在哪；其余套卷待补录
- 错题本：按「套卷 + 题号」去重，一键只练错题
- 答案：8 套已预填，可在「录入答案」里粘贴或点选修改
- 数据备份：导出 / 导入 JSON（可用于跨设备迁移）
- 做题中途刷新不丢（草稿自动保存），支持暂停计时、答题卡跳题

## 账号与数据说明（重要）

这是一个纯静态网页（GitHub Pages 托管，无服务器），账号与数据的存储方式如下：

- 账号信息和刷题数据都保存在**访问它的那个浏览器**（localStorage）里，**不同设备之间不自动同步**
- 密码使用 PBKDF2-SHA256（随机盐、20 万次迭代）哈希后存储，绝不保存明文
- 同一浏览器上不同账号的数据互相隔离、互不可见
- 跨设备迁移：旧设备登录 → 「数据备份」→ 导出 JSON → 新设备登录同一账号 → 导入
- 忘记密码无法找回（数据只在本机），请牢记密码，或提前导出备份
- 属于轻量级账号隔离，不是服务器级安全体系，请勿在公共电脑上保持登录
